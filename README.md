# TacticsInMenschÄrgereDichNicht

**MadnLab** — a measurement engine for the question: do optional rules and
piece-movement strategies in *Mensch ärgere Dich nicht* (the German Ludo
variant) have statistically measurable effects, and how large are they?

The product is measurement series with uncertainty estimates. Simulated games
are a by-product.

## Status

Complete. **16,430,642 games** across 387 cells, all 40 pre-registered
hypotheses evaluated, results in [docs/results.md](docs/results.md).

## Headline results

**RQ-1 — mandatory capture does not make games more dynamic: not supported.**
It does raise the dispersion of game length (CV ratio 1.169, 95% CI lower
bound 1.164), but only one of the three required dynamism conjuncts holds.
Lead changes per turn move *significantly in the opposite direction*: with
mandatory capture the lead changes less often. Games get longer and more
variable in length, not more eventful.

**RQ-2 — the rule variants move length, almost never win rate.** 11 of 18
tests reject. `free_entry` shortens the game by 208 rounds, mandatory capture
lengthens it by 64, `dreimal würfeln` shortens it by 70. Of nine win-rate
contrasts, two survive.

**RQ-3 — no movement strategy beats random: 0 of 4.** SPREAD, FOCUS_FRONT and
FOCUS_REAR all sit within ±0.3 pp of 1/k at 200,000 games per cell, against a
resolution of 0.19 pp. That is a result, not a power failure.

**RQ-4 — 4 of 10.** EX-5's pre-registered decomposition holds: the pattern
effect is −2.05 rounds and the geometry effect −11.7, which is why §8 forbids
publishing their sum as a pattern effect.

**The largest measured effect was not a hypothesis.** Two adjacent SPREAD
players win 35.3% against 64.7% — a **29.5 pp** seat advantage. The same
seating with RANDOM play gives 3.5 pp. The effect needs both the geometry and
the strategy, and it is two orders of magnitude larger than anything the study
asked about. It is reported as descriptive, uncorrected, and in need of its own
pre-registered replication.

## Layout

| Path | What it is |
|---|---|
| `src/madnlab/engine/` | Board geometry, rules, legal moves, the game loop. One `legal_moves` owns legality (GM-7). |
| `src/madnlab/agents/` | The five policies. Each consumes exactly one RNG draw per decision, deterministic ones included (D-37). |
| `src/madnlab/eventlog/` | Canonical JSON event log and summary rows, plus the replay validator AK-3 runs. |
| `src/madnlab/analysis/` | Intervals, multiplicity, the §6.4 estimators and family bindings, and the report renderer. Stdlib only — no SciPy. |

| `tests/` | 137 tests: AK-1 rule conformance, AK-2 determinism, AK-3 replay, AK-4 gate scope, AK-8/8b/8c estimators, AK-9 metric cross-validation. |

## Reproducing

Run one campaign:

```bash
python -m madnlab.run.cli run campaigns/ex2.json --out runs/ex2 --workers 48
```

Build the report from every campaign:

```bash
python -m madnlab.run.cli report runs/ex1 runs/ex2 --out docs/results.md --workers 16
```

Every number is a function of the master seeds in `campaigns/*.json` and the
analysis seed (NF-6, NF-7). Worker count changes wall-clock and nothing else —
in the runner because shards seal by ascending game index (D-33), and in the
analysis because each contrast's seed comes from its index rather than from
execution order.

## Rule baseline

The baseline is the official Schmidt Spiele rule set, pinned to a named pair of
editions: **Art. 49020/49021 (2006)** for structure (2–6 players, board
geometry) and **Art. 51204 (2023)** for mechanical clauses absent from it. Each
cross-edition adoption is recorded individually in the ledger. Rule claims
carry the German source text and the edition they were verified against.

## Pre-registration

The specification is frozen at the git tag `prereg-v1`. Every campaign config
and summary row records the `prereg_version` it ran under, and every published
row reads `prereg-v1`. Any later change to the metrics or the experiment plan
is an amendment with its own ledger row. All pre-registered metrics are
reported for every cell regardless of outcome.

**The freeze was late, and the record says so.** The tag was created after
EX-1 and the first campaign submissions had already run under a placeholder.
All of that data was discarded and regenerated under the tag rather than
relabelled — runs are deterministic from the master seed, so regeneration costs
wall-clock only. No §6.4 hypothesis had been evaluated at any point before the
freeze, so the freeze still precedes the analysis. D-73 carries the full
record; D-74 to D-77 record the defects found after it, including two in the
analysis code that the first real report exposed.

## Scope note

Results are statements about the defined agent policies, not about human play.
For the flags whose effect is mediated by agent choice, the measured effect is
a bound set by the policy, and the direction of that bound is part of the
pre-registered estimand.
